# Spoolman Home Assistant Add-on

[![Spoolman Version](https://img.shields.io/badge/Spoolman-v0.27.0-blue.svg)](https://github.com/Donkie/Spoolman)

Keep track of your 3D printer filament spools directly within Home Assistant.

## Features
- Complete standalone filament management backend and web interface.
- Integration ready for Bambu Lab, Klipper, Moonraker, and SpoolmanSync.
- Persistent SQLite database stored in `/config/spoolman/spoolman.db`.

## Installation
1. Add this repository to your Home Assistant Add-on Store:
   `https://github.com/Le-Maxime/HA-Addons`
2. Search for **Spoolman** and click **Install**.
3. Start the add-on and access the web UI on port `8000`.
