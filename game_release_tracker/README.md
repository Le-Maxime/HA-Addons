# Game Release Tracker Home Assistant Add-on

Automated game release tracker monitoring hypervisor and crack releases from **DenuvOwO**, **Artifact**, and **voices38** on cs.rin.ru and Reddit. Features Telegram photo notifications, Steam metadata resolution, and an interactive release catalog bot.

## Features
- ⚡️ Tracks DenuvOwO (Hypervisor) and Artifact (Hypervisor) posts on cs.rin.ru
- 🔓 Tracks voices38 (Crack) posts on cs.rin.ru and Reddit
- 🖼 Auto-fetches game cover artwork from Steam CDN
- 📦 Automatic Steam BuildID detection with direct SteamDB patch notes links
- 🤖 Full-featured Telegram bot with interactive inline catalog, pagination, and search
- 🛡 Built-in admin access control for private chats and Telegram channels/groups
- 📢 Optional Discord Webhook notifications
