# Game Release Tracker

Дополнение для Home Assistant, отслеживающее публикации игровых взломов и гипервизорных релизов с автоматической отправкой карточек в Telegram (с обложками из Steam, ссылками на патчноуты SteamDB и прямыми ссылками на загрузку) и интерактивным ботом-каталогом.

## 🎯 Поддерживаемые релизеры:
* ⚡️ **DenuvOwO** (Гипервизор на cs.rin.ru)
* ⚡️ **Artifact** (Гипервизор на cs.rin.ru)
* 🔓 **voices38** (Кряки на cs.rin.ru и Reddit)

## 🚀 Быстрый старт и настройка

### Шаг 1. Создание Telegram-бота
1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям: укажите имя и юзернейм (например, `MyGameTrackerBot`).
3. Скопируйте полученный **HTTP API Token** и вставьте его в поле `telegram_token`.
4. Нажмите ссылку на созданного бота и нажмите **Start** (`/start`).
5. Узнайте ваш личный цифровой Telegram ID (например, через бота [@myidbot](https://t.me/myidbot) командой `/getid`) и вставьте его в поле `telegram_chat_id`.

---

### Шаг 2. Получение Cookies авторизации с cs.rin.ru
Форум cs.rin.ru защищён от спама и гостевых запросов строгими ограничениями поиска (Search flood limit). Для стабильной проверки новых постов требуются cookies авторизованной учетной записи:

1. Войдите в свой аккаунт на [cs.rin.ru/forum/](https://cs.rin.ru/forum/).
2. Откройте панель разработчика браузера (нажмите **F12**).
3. Перейдите на вкладку **Application** (или **Хранилище** / **Storage**) -> **Cookies** -> `https://cs.rin.ru`.
4. Скопируйте значения и вставьте в конфигурацию дополнения:
   * `csrinru_phpbb3_u` — ваш ID пользователя
   * `csrinru_phpbb3_k` — ключ автовхода
   * `csrinru_phpbb3_sid` — идентификатор текущей сессии
   * `securitytoken` — токен антибот-проверки (если отображается)
   * `securitytoken_expiration` — срок действия токена

---

### Шаг 3. Запуск дополнения
1. Нажмите кнопку **Сохранить** во вкладке «Конфигурация».
2. Перейдите во вкладку **Инфо** и нажмите **Запустить**.
3. Включите переключатели **Запуск при загрузке системы** и **Сторожевой таймер**.
4. Проверьте вкладку **Журнал** (Logs). Вы увидите успешный запуск бота и первый цикл проверки.

---

## 📱 Возможности Telegram-бота

* 🔔 **Уведомления о релизах:** При публикации нового взлома или обновления бот присылает карточку с обложкой Steam, номером билда со ссылкой на SteamDB и кнопками загрузки.
* 📁 **Интерактивный каталог:** В меню бота доступна кнопка каталога с разделами:
  * ⚡️ **Гипервизор** (релизы DenuvOwO и Artifact)
  * 🔓 **Кряки** (релизы voices38)
  * 🔍 **Поиск** по базе релизов
* 👥 **Контроль доступа:** Посторонние пользователи при нажатии `/start` видят запрос на доступ. Заявка моментально отправляется администратору с кнопками «Одобрить» / «Заблокировать».
* 💬 **Поддержка групп и каналов:** Бота можно добавить в группу или канал. Для активации уведомлений в группе администратор должен одобрить запрос через кнопку бота.
