# Antigravity Workspace

Дополнение для Home Assistant, разворачивающее изолированную среду для автономного AI-агента **Google Antigravity (`agy`)** с полноценным веб-терминалом на боковой панели Home Assistant (Ingress).

Аддон спроектирован для задач **автономного программирования, автоматизаций и анализа переписок в Telegram**.

---

## 🚀 Особенности

* 🤖 **Google Antigravity (`agy`):** Полноценный агентный каркас от Google с поддержкой планирования, написания кода, запуска тестов, вызова MCP-инструментов и управления файлами.
* 💬 **Готов к анализу Telegram:** Из коробки установлены библиотеки `telethon`, `pyrogram`, `tgcrypto`, `pandas`, `aiohttp`, `requests` в изолированном Python venv (`/opt/venv`).
* 🖥️ **Ingress Web-Терминал (`ttyd`):** Терминал открывается прямо в боковом меню Home Assistant, защищен встроенной авторизацией и не требует открытия портов наружу.
* 🔄 **Фоновые сессии (`tmux`):** Работает внутри сессии `tmux` — если закрыть вкладку браузера или перезайти с мобильного телефона, процессы не завершаются, агент продолжает выполнять работу в фоне.
* 💾 **Персистентность данных:** Все сессии Telegram, ключи авторизации и код сохраняются на постоянном хранилище (`/data` и `/share/antigravity_projects`).
* 📁 **Доступ к файлам:** Смонтированы папки `/share` и `/homeassistant` (`/config`).

## 🛠️ Быстрый старт

1. После установки включите тумблеры:
   * **Запуск при загрузке системы**
   * **Показывать на боковой панели**
2. Запустите дополнение.
3. В левом меню нажмите пункт **Antigravity**.
4. В открывшейся консоли запустите агент:
   ```bash
   agy
   ```
5. Пройдите быструю авторизацию Google / Gemini по инструкции на экране терминала.

---

## 📱 Работа с Telegram

Для чтения переписок и чатов агент может использовать клиентскую сессию **Telethon**:
1. Получите `api_id` и `api_hash` на [my.telegram.org](https://my.telegram.org).
2. Попросите агента:
   > «Напиши Python-скрипт на Telethon для чтения сообщений из чата X. Сохрани сессию в `/data/telegram_sessions/my_session`. Выгрузи последние 100 сообщений, сделай саммари договоренностей и сохрани отчет в `/share/antigravity_projects/summary.md`».
3. При первом запуске в терминале скрипт запросит номер телефона и код подтверждения (сессия сохранится в файл и в дальнейшем будет работать автоматически).
