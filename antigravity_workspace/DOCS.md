# Документация Antigravity Workspace

## Назначение
Аддон предоставляет автономную рабочую среду для AI-агента кодинга и анализа данных Antigravity CLI.

## Структура путей:
* `/data/workspace` — домашняя рабочая директория по умолчанию.
* `/data/telegram_sessions` — каталог для постоянных файлов сессий Telegram (`.session`).
* `/data/.gemini` — директория настроек и токенов авторизации агента Antigravity.
* `/share/antigravity_projects` — папка проектов, доступная по сети (через Samba/SMB).
* `/homeassistant` — доступ к конфигурационным файлам Home Assistant (`configuration.yaml`, автоматизации и т.д.).

## Полезные команды в терминале:
* `agy` — запуск интерактивной консоли агента Antigravity.
* `agy --help` — список доступных флагов командной строки.
* `tmux a` — переподключение к активной сессии (выполняется автоматически при открытии).
* `python -m pip list` — просмотр установленных Python-пакетов в venv.
